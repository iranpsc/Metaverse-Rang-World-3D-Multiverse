# متارنج — MetaRangeRespawn (مستندات v3.9.0)

سیستم ثبت و اشتراک‌گذاری موقعیت ریسپان (Spawn) آواتار: پنل مالک در یونیتی + سرور Node.js.
مالک موقعیت‌های دلخواه را با نام یونیک ثبت می‌کند و لینک/QR را برای بازیکن می‌فرستد؛ بازیکن با باز کردن لینک دقیقاً در همان نقطه اسپان می‌شود.

| | |
|---|---|
| **نسخهٔ پکیج یونیتی** | **v3.9.0** |
| نسخهٔ سرور (`/api/health`) | `3.1` (شمارهٔ مستقل سرور) |
| فضای‌نام کد | `MetaRange.Avatar` |
| مسیر Tool | `Tools ▸ متارنج ▸ راه‌اندازی سیستم ریسپان آواتار` |
| Base سرور | `http://localhost:3000` |

> شمارهٔ نسخهٔ سرور (`3.1`) عمداً از نسخهٔ پکیج یونیتی جداست؛ سرور فقط API است و تغییرات UI روی آن اثری ندارد.

---

## شروع سریع (۳ دقیقه)

```bash
# ۱) سرور
cd metaverse-spawn-server
npm install
node index.js          # باید در کنسول: متارنج v3.1 — سرور ریسپان آواتار
```

```text
۲) یونیتی: Player را در Hierarchy انتخاب کنید
   Tools ▸ متارنج ▸ راه‌اندازی سیستم ریسپان آواتار

۳) Play کنید:
   پنل چپ  → نام محیط را بنویسید → «ساخت فایل محیط»
   پنل راست → تیک «مالک هستم» → نام موقعیت → «ثبت موقعیت»
   سپس در سکشن «لینک و QR»: «کپی لینک» یا «دانلود لینک» یا «دانلود QR»
```

اگر بدون ساخت محیط «ثبت موقعیت» را بزنید، فقط پیام راهنما نمایش داده می‌شود و **هیچ درخواستی به سرور ارسال نمی‌گردد**.

## دو پنل UI

| پنل | آبجکت ریشه | آبجکت پنل | کار |
|-----|-----------|-----------|-----|
| **چپ** — ساخت محیط | `MetaRange_CreateEnvCanvas` (Canvas مستقل) | `MetaRange_LeftCreatePanel` | `EnvNameInput` + `CreateEnvButton` («ساخت فایل محیط») + `CreateEnvResult` |
| **راست** — مالک | `Canvas` اصلی صحنه | `MetaRangeRootPanel` | سه سکشن: `Section_Owner`، `Section_Result`، `Section_PositionList` |

ساختار پنل راست:

| سکشن | محتوا |
|------|-------|
| `Section_Owner` — «۱) پنل مالک» | `OwnerToggle` («مالک هستم») · `LivePositionText` · `PositionNameInput` · `RegisterPositionButton` («ثبت موقعیت») · `RegisterStatusText` |
| `Section_Result` — «لینک و QR» *(پیش‌فرض مخفی)* | `LinkText` · `QrRow/QrRawImage` · `LinkButtons` · `LinkStatusText` |
| `Section_PositionList` — «۲) موقعیت‌های ذخیره‌شده» | `EmptyListText` · `PositionsScroll` (کارت‌ها داخل آن ساخته می‌شوند) |

## دکمه‌های خروجی لینک (v3.9.0)

| دکمه | آبجکت | رفتار |
|------|-------|-------|
| **کپی لینک** | `CopyLinkButton` | لینک کامل در کلیپ‌بورد سیستم + پیام سبز «لینک کپی شد» |
| **دانلود لینک** | `DownloadLinkButton` | فایل متنی `spawn_{env}_{positionId}.txt` با لینک در **یک خط** (UTF-8 بدون BOM) |
| **دانلود QR** | `DownloadQrButton` | تصویر PNG کد QR |

تا وقتی لینکی ساخته نشده باشد، دو دکمهٔ اول **غیرفعال** هستند و پیام «ابتدا یک موقعیت ثبت کنید» نشان داده می‌شود.
