# ۰۵ — یکپارچه‌سازی با برنامهٔ اصلی (v3.5.0)

این سند قرارداد بین پکیج متارنج و بازی/پروژهٔ شماست.

## ۱) قرارداد Player

| مورد | الزام | توضیح |
|------|-------|-------|
| تگ `Player` | **ضروری** | Tool هنگام راه‌اندازی، اگر تگ وجود نداشته باشد آن را اضافه می‌کند. `OwnerPanel.EnsureAvatar` و `SpawnFromURL` هر دو با همین تگ آواتار را پیدا می‌کنند. |
| نام آبجکت | ترجیحاً یکی از این‌ها | `Player` · `MetaRangeAvatar` · `Avatar` · `LocalPlayer` · `XR Origin` · `XR Rig` (به‌عنوان fallback جست‌وجو می‌شوند) |
| فیلد `Avatar` در Inspector | توصیه می‌شود | اگر آبجکت در زمان اجرا تعویض شد، Tool نمی‌تواند کمک کند؛ `EnsureAvatar` خودش دوباره پیدا می‌کند |
| `CharacterController` / `Rigidbody` | مجاز | `MoveAvatarTo` هر دو را مدیریت می‌کند (خاموش/روشن کردن CC و صفر کردن سرعت RB) |

### اتصال دستی آواتار

```csharp
FindObjectOfType<OwnerPanel>().SetAvatar(playerTransform);   // در زمان اجرا
```

یا از Inspector: کلیک راست روی کامپوننت `OwnerPanel` ← **MetaRange ▸ اتصال آواتار با تگ Player**.

## ۲) Hook‌های آمادهٔ `SpawnFromURL`

| متد | چه زمانی صدا بزنید |
|-----|-------------------|
| `ApplySpawnFromUrl()` | بعد از لود صحنه، اگر می‌خواهید خودِ پکیج `env`/`spawn` را از URL بخواند |
| `ApplySpawn(env, spawn)` | اگر برنامهٔ خودتان پارامترها را از جای دیگری خوانده (مثلاً از منو یا QR داخلی) |
| `TryGetUrlParams(out env, out spawn)` | اگر فقط می‌خواهید بدانید لینک شامل پارامتر هست یا نه |
| `SetAvatar(Transform)` | بعد از ساخته شدن آواتار (اگر Tool آن را ست نکرده) |
| `SetDefaults(Vector3, Quaternion)` | برای تعیین نقطهٔ اسپان پیش‌فرض خودتان |

نمونهٔ کامل:

```csharp
using MetaRange.Avatar;
using UnityEngine;

public class MetaRangeBootstrap : MonoBehaviour
{
    public Transform player;

    IEnumerator Start()
    {
        yield return null;                       // بعد از لود صحنه

        var spawn = FindObjectOfType<SpawnFromURL>();
        if (spawn == null) { Debug.LogError("MetaRange_SpawnSystem not found"); yield break; }

        spawn.SetAvatar(player);

        if (spawn.ApplySpawnFromUrl())
            Debug.Log("اسپان از لینک انجام شد");
        else
            Debug.Log("پارامتری در لینک نبود ⇒ اسپان پیش‌فرض");
    }
}
```

> اگر Scene Loader خودتان را دارید، `SpawnFromURL` را در حالت خودکار (`Start`) رها نکنید مگر واقعاً Scene Loader ندارید؛ در غیر این صورت اسپان قبل از آماده شدن آواتار انجام می‌شود.

## ۳) تنظیماتی که Tool ست می‌کند و نباید دستکاری شود

| کامپوننت | فیلدهای Bind‌شده |
|-----------|-----------------|
| `EnvironmentCreator` | `nameInput`، `createButton`، `resultText`، `serverUrl` |
| `OwnerPanel` | `ownerToggle`، `avatar`، `livePosText`، `positionNameInput`، `registerButton`، `registerStatusText`، `sectionResult`، `linkText`، `qrImage`، `downloadQrButton`، `copyLinkButton`، `downloadLinkButton`، `linkStatusText`، `sectionPositionList`، `emptyListText`، `cardContainer`، `cardPrefab`، `serverUrl`، `playBaseUrl` |
| `PositionCardUI` (روی prefab) | `idLabel`، `posLabel`، `dateLabel`، `editButton`، `editRow`، `nameField`، `xField`، `yField`، `zField`، `confirmButton`، `cancelButton` |
| `SpawnFromURL` | `avatarTransform`، `serverUrl` |

مقادیر ثابت در Tool:

| ثابت | مقدار |
|------|-------|
| `ServerUrl` | `http://localhost:3000` |
| `PlayBaseUrl` | `https://metarange.adfam.com/play` |

برای تغییر `playBaseUrl` می‌توانید فیلد را در Inspector همان پنل ویرایش کنید (Tool در اجرای بعدی دوباره مقدار پیش‌فرض را می‌نویسد).

## ۵) نکات تحویل به کارفرما

| موضوع | توضیح |
|-------|-------|
| لاگ سرور | `metaverse-spawn-server/logs/server.log` — هر درخواست با متد، مسیر، کد و خلاصهٔ بدنه |
| داده‌ها | یک فایل JSON به‌ازای هر محیط در `metaverse-spawn-server/data/environments/` |
| پشتیبان‌گیری | کپی گرفتن از همین پوشه = کل اطلاعات موقعیت‌ها |

| امنیت | سرور احراز هویت ندارد؛ برای محیط عملیاتی پشت reverse proxy با احراز هویت قرار دهید |
| مقیاس | هر درخواست یک خواندن/نوشتن کامل فایل JSON است؛ برای بار سنگین به دیتابیس مهاجرت کنید |
