### خروجی لینک و QR (v3.5.0)

```
UpdateLinkButtonsState(bool hasLink)      → copyLinkButton.interactable / downloadLinkButton.interactable
SetLinkStatus(string msg, Color color)    → linkStatusText.text / .color

OnCopyLink()                              ← دکمهٔ «کپی لینک»
   ├─ currentLink خالی؟  → «ابتدا یک موقعیت ثبت کنید» و return
   ├─ موفق: GUIUtility.systemCopyBuffer = currentLink
   │          → «لینک کپی شد» + Debug.Log
   └─ Exception (WebGL/مرورگر):
              → «کپی خودکار ممکن نشد — لینک را دستی انتخاب کنید» + Debug.LogWarning

OnDownloadLink()                          ← دکمهٔ «دانلود لینک»
   ├─ currentLink خالی؟  → «ابتدا یک موقعیت ثبت کنید» و return
   ├─ fileName = "spawn_" + SanitizePositionName(StoredEnvironmentName یا "env")
   │                        + "_" + SanitizePositionName(currentSpawnId) + ".txt"
   ├─ #if UNITY_EDITOR → EditorUtility.SaveFilePanel("ذخیره لینک ریسپان", "", fileName, "txt")
   │                     لغو ⇒ «ذخیره لغو شد» و return
   ├─ #else            → Path.Combine(Application.persistentDataPath, fileName)
   ├─ File.WriteAllText(path, currentLink, new UTF8Encoding(false))   ← بدون BOM، یک خط
   └─ موفق ⇒ «فایل لینک ذخیره شد» + لاگ مسیر | خطا ⇒ «خطا در ذخیره فایل» + LogError

OnDownloadQr()                            ← دکمهٔ «دانلود QR»
   ├─ qrImage.texture is not Texture2D ⇒ «QR هنوز دانلود نشده است»
   ├─ #if UNITY_EDITOR → SaveFilePanel("ذخیره QR کد ریسپان", "", "qr_spawn", "png")
   ├─ #else            → persistentDataPath/qr_spawn.png
   └─ File.WriteAllBytes(path, tex.EncodeToPNG())

LoadQr(string data)                       ← زنجیرهٔ fallback
   ① serverUrl + "/api/qr?data=" + EscapeURL(data)      (اگر useLocalServerQr)
   ② qrPrimaryTemplate.Replace("{DATA}", EscapeURL(data))
   ③ qrFallbackTemplate.Replace("{DATA}", EscapeURL(data))
   ✗ هر سه ناموفق ⇒ LogError + یادآوری اعتبار لینک متنی
   timeout = 12 برای هر تلاش · هدر User-Agent مرورگر
```

| `ExitEditMode()` | خروج از بیرون (وقتی کارت دیگری ویرایش می‌شود) |
| `SetMode(bool)` | نمایش/پنهان‌سازی اجزا + هایلایت آبی کارت + `LayoutRebuilder.MarkLayoutForRebuild` |

> چرخش: در ویرایش قابل تغییر است — میدان `Rx/Ry/Rz` (درجه) زنده از `owner.AvatarRotation` پر می‌شود و با «تأیید» به‌صورت `rotation{x,y,z,w}` ذخیره و (در صورت فعال بودن) روی آواتار اعمال می‌گردد.
