# ۰۴ — لینک بازیکن و اسپان (v3.5.0)

## فرمت لینک

```
{playBaseUrl}?env={environmentName}&spawn={positionId}
```

| پارامتر | معنی | نمونه |
|---------|------|-------|
| `env` | نام محیط (همان `StoredEnvironmentName`) | `demo_hall` |
| `spawn` | شناسهٔ موقعیت (نام یونیک) | `ورودی_اصلی` · `pos_4F7A21` |

نمونه‌های واقعی:

```
https://dev-world-3d.metarang.com/game?env=demo_hall&spawn=pos_4F7A21
https://dev-world-3d.metarang.com/game?env=test_webgl&spawn=ورودی_اصلی
```

### دربارهٔ نام فارسی در لینک

`OwnerPanel` لینک را به شکل **خام** می‌سازد (`playBaseUrl + "?env=" + env + "&spawn=" + posId`) تا متن نمایش‌داده‌شده برای مالک خوانا بماند؛
مرورگر هنگام ارسال، خودش نام فارسی را **percent-encode** می‌کند:

```
ورودی_اصلی  ⇄  %D8%AF%D8%B1%D9%88%D8%A7%D8%B2%D9%87_%D8%A7%D8%B5%D9%84%DB%8C
```

سمت سرور و سمت `SpawnFromURL` هر دو این دو حالت را می‌پذیرند:

| سمت | رفتار |
|-----|-------|
| `OwnerPanel.LoadQr` | `UnityWebRequest.EscapeURL(link)` پیش از ساخت URL سرویس QR |
| `SpawnFromURL.FetchSpawn` | `EscapeURL(env)` و `EscapeURL(spawn)` ⇒ URL همیشه معتبر |
| `SpawnFromURL.GetParam` | `UnityWebRequest.UnEscapeURL` ⇒ نام فارسی درست بازیابی می‌شود |
| سرور (`safeName`) | بعد از decode، فقط حروف فارسی/لاتین، ارقام، `-` و `_` را می‌پذیرد |

## کامپوننت `SpawnFromURL`

این کامپوننت روی آبجکت `MetaRange_SpawnSystem` قرار می‌گیرد (بدون UI).

| فیلد | پیش‌فرض | کار |
|------|---------|-----|
| `serverUrl` | `http://localhost:3000` | آدرس سرور |
| `avatarTransform` | ست‌شده توسط Tool | اگر نال باشد، در `Start` با تگ `Player` پیدا می‌شود |
| `defaultPosition` | `(0, 1, 0)` | اسپان جایگزین در صورت خطا/نبود پارامتر |
| `defaultRotation` | `identity` | چرخش جایگزین |

### مسیر اجرای خودکار

```
Start()  →  avatarTransform نال بود ⇒ GameObject.FindWithTag("Player")
        →  ParseAndSpawn() → ApplySpawnFromUrl()
```

### API عمومی (برای برنامهٔ اصلی)

| متد | امضا | رفتار |
|-----|------|-------|
| خواندن پارامترها | `static bool TryGetUrlParams(out string env, out string spawn)` | اگر هر دو پارامتر در URL جاری باشند `true` |
| اسپان از URL جاری | `bool ApplySpawnFromUrl()` | اگر پارامترها نبود ⇒ `Spawn(defaultPosition)` و `false` |
| اسپان با مقادیر دلخواه | `Coroutine ApplySpawn(string env, string spawn)` | وقتی برنامهٔ خودتان `env`/`spawn` را خوانده |
| ست کردن آواتار | `void SetAvatar(Transform t)` | — |
| ست کردن پیش‌فرض‌ها | `void SetDefaults(Vector3 pos, Quaternion rot)` | — |
| خواندن URL جاری | `static string GetCurrentUrl()` | — |

### منبع URL جاری

| محیط | منبع |
|------|------|
| WebGL | `Application.absoluteURL` (آدرس واقعی مرورگر) |
| ادیتور / بیلد | `Application.absoluteURL`؛ اگر خالی بود، آرگومان خط فرمان `url=…` |

نمونهٔ تست در ادیتور/بیلد:

```bash
# ویندوز
MyGame.exe url="http://localhost:3000/?env=demo_hall&spawn=pos_4F7A21"
```

## دریافت مختصات از سرور

```
GET /api/get-position?env={EscapeURL(env)}&spawn={EscapeURL(spawn)}
```

| پاسخ | رفتار `SpawnFromURL` |
|------|----------------------|
| `200` + `{position, rotation}` | `JsonUtility.FromJson<PositionEntry>` ⇒ `SetPositionAndRotation` روی آواتار |
| `404 Position/Environment not found` | لاگ خطا + `Spawn(defaultPosition)` |
| خطای شبکه | یک‌بار تلاش مجدد با `127.0.0.1` ⇒ در صورت ناموفقی `Spawn(defaultPosition)` |
| JSON بدون `position` | `Spawn(defaultPosition)` |

لاگ‌های مفید:

```
[SpawnFromURL] اسپان در (194.50, -37.90, 0.00)
[SpawnFromURL] خطا در API — url=… responseCode=404 error= … body={"error":"Position not found"}
[SpawnFromURL] پارامتر env/spawn در URL یافت نشد — اسپان در موقعیت پیش‌فرض.
```

## سناریوی کامل (لاتین + فارسی)

```text
۱) مالک در پنل چپ محیط test_webgl را می‌سازد
۲) در پنل راست تیک «مالک هستم» می‌زند و آواتار را به (194.5, -37.9, 0) می‌برد
۳) نام موقعیت: «دروازهٔ شمالی» ⇒ «ثبت موقعیت»
۴) لینک: https://dev-world-3d.metarang.com/game?env=test_webgl&spawn=دروازهٔ_شمالی
۵) «کپی لینک» ⇒ پیام «لینک کپی شد»
۶) بازیکن لینک را باز می‌کند
۷) مرورگر: ?env=test_webgl&spawn=%D8%AF%D8%B1%D9%88%D8%A7%D8%B2%D9%87_%D8%B4%D9%85%D8%A7%D9%84%DB%8C
۸) سرور لاگ می‌کند:
   GET /api/get-position -> 200  {"env":"test_webgl","spawn":"%D8%AF…"}
۹) آواتار بازیکن در (194.50, -37.90, 0.00) ظاهر می‌شود
```

> نکته: «دروازهٔ شمالی» پس از `SanitizePositionName` به «دروازهٔ_شمالی» تبدیل می‌شود (فاصله ← `_`).

## اگر برنامهٔ اصلی Scene Loader خودش را دارد

`SpawnFromURL` را از `Start` خودکار استفاده نکنید؛ به‌جای آن بعد از لود صحنه:

```csharp
using MetaRange.Avatar;

public class MyGameLoader : MonoBehaviour
{
    public Transform player;

    void AfterSceneLoaded()
    {
        var spawn = FindObjectOfType<SpawnFromURL>();
        spawn.SetAvatar(player);

        if (spawn.ApplySpawnFromUrl())       // پارامترها در URL بودند
            Debug.Log("اسپان از لینک انجام شد");
        else
            Debug.Log("لینک بدون پارامتر ⇒ اسپان پیش‌فرض");
    }
}
```
