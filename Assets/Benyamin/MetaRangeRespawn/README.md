# متارنج — سیستم مدیریت موقعیت ریسپان آواتار (v3.5.0)

پکیج یونیتی + سرور Node.js برای ساخت فایل JSON محیط، ثبت/ویرایش موقعیت آواتار و تولید لینک و QR ریسپان.

**مستندات کامل (v3.5.0):** [`Docs/README.md`](Docs/README.md)

## دو پنل

| پنل | آبجکت | کار |
|-----|-------|-----|
| **چپ** (Create Environment) | `MetaRange_CreateEnvCanvas ▸ MetaRange_LeftCreatePanel` | نام محیط + دکمهٔ «ساخت فایل محیط» + پیام نتیجه |
| **راست** (Owner) | `Canvas ▸ MetaRangeRootPanel` | تیک «مالک هستم» + موقعیت زنده + «ثبت موقعیت» + لینک/QR + لیست کارت‌ها |

## دکمه‌های خروجی لینک

| دکمه | نتیجه |
|------|-------|
| **کپی لینک** | لینک کامل در کلیپ‌بورد + پیام «لینک کپی شد» (در WebGL اگر کلیپ‌بورد مسدود باشد، پیام راهنما نمایش داده می‌شود) |
| **دانلود لینک** | فایل متنی `spawn_{env}_{positionId}.txt` با لینک در یک خط (UTF-8 بدون BOM) |
| **دانلود QR** | تصویر PNG کد QR |

تا وقتی موقعیتی ثبت نشده باشد، دو دکمهٔ اول غیرفعال هستند.

## شروع سریع

1. **سرور**:
   ```bash
   cd metaverse-spawn-server
   npm install
   node index.js
   ```
2. **یونیتی**: Player را انتخاب کنید → **Tools ▸ متارنج ▸ راه‌اندازی سیستم ریسپان آواتار**
3. **Play**: پنل چپ ← «ساخت فایل محیط» | پنل راست ← تیک مالک ← «ثبت موقعیت» ← «کپی لینک»

> اگر بدون ساخت محیط «ثبت موقعیت» را بزنید، هشدار راهنما نمایش داده می‌شود و درخواستی ارسال نمی‌گردد.
