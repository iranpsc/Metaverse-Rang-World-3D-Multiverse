# محدودیت‌های پلتفرمی - سیستم ارتباطی متاورس

## 🔹 WebGL (مرورگر)

### الزامات اساسی
- **فقط از طریق HTTPS** قابل استفاده است (حتی برای لوکال‌هاست)
- برای تست لوکال نیاز به گواهی SSL self-signed با ابزار `mkcert`
- دسترسی به میکروفون **نیاز به اقدام کاربر** (کلیک روی دکمه) دارد
- سقف ذخیره‌سازی `localStorage`: حدود ۵ مگابایت
- اجرای پس‌زمینه ممکن نیست (تب مرورگر باید فعال باشد)

### راه‌حل برای لوکال‌هاست با HTTPS
```bash
# نصب mkcert (یک‌بار)
npm install -g mkcert

# ایجاد گواهی برای لوکال‌هاست
mkcert -install
mkcert localhost

# خروجی: localhost.pem و localhost-key.pem
# این فایل‌ها را در سرور لوکال استفاده کنید
