[PinkFihs studio] This Script Made To Configure The Mirror Server Using .json File

=======================================
* to use you need network manager in the scene.
* you can put the script at the network manager child.
* the config file loads from file inside the game server folder
* the .json file must be next to the .x86_64 excutable file so the script can find it.
* DO NOT cahnge the config file!
* you can find the config file in the MetaRGB document.
